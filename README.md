# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Ссылка на опубликованный проект

GitHub Pages: **https://violetta11383829.github.io/kr1-html-css-shop/**

## Структура проекта

- `index.html` – главная страница;
- `catalog.html` – каталог товаров;
- `product.html` - карточка товара;
- `order.html` - оформление заявки;
- `contacts.html` – контактная информация;
- `css/style.css` – файл стилей;
- `js/main.js` – файл JavaScript;
- `images/` – папка для изображений;
- `.gitignore` – список файлов, исключённых из Git;
- `README.md` – описание проекта.

## Используемые технологии

- HTML;
- CSS (переменные, Flexbox, Grid);
- JavaScript (модальное окно, валидация формы);
- Git;
- GitHub;
- GitHub Pages.

## Реализованные элементы интерфейса

- Семантическая HTML-разметка: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`;
- Единая навигация на всех страницах;
- Якорные ссылки на главной странице;
- Хлебные крошки на внутренних страницах;
- Модальное окно с формой заявки (`<dialog>`);
- Базовая HTML-валидация и JS-обработка формы;
- Сообщение об успешной отправке формы;
- CSS-переменные в `:root`;
- Состояния `:hover`, `:focus-visible`, `:disabled`;
- Flexbox для навигации и карточек товаров;
- CSS Grid для сетки карточек и страницы каталога с фильтрами.

Тема контрольной работы №1: «HTML и CSS: разработка многостраничного сайта».

- главную страницу;
