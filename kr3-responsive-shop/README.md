# Контрольная работа №3 — ShopProject

Тема: «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

## Основа проекта
Проект перенесён из контрольной работы №1. Bootstrap не используется. Изображения повторно используются из папки `../images/` исходного репозитория КР1.

## Практическая работа №12 — адаптивная вёрстка
- добавлен отдельный файл `css/responsive.css`;
- адаптивные стили подключены на всех пяти HTML-страницах после основного CSS;
- используется подход Mobile First и медиазапросы `min-width`;
- адаптированы навигация, hero-блок, карточки, каталог и фильтр;
- добавлены `max-width: 100%`, `picture`, `srcset`, `sizes`, `width`, `height` и `loading="lazy"`;
- адаптированы форма заявки, таблица характеристик и модальное окно.

## Практическая работа №13 — A11y и Lighthouse
- добавлена ссылка пропуска к основному содержимому;
- добавлены `id="main"`, семантические подписи навигации и `aria-current="page"`;
- проверены alt-описания изображений;
- добавлены видимые стили фокуса;
- таблица характеристик размечена через caption, thead, tbody, th и td;
- обработчик JavaScript проверяет наличие элементов, управляет модальным окном и возвращает фокус к кнопке открытия;
- формы демонстрационные: серверная отправка данных не реализована.

## Проверка адаптивности
Проверить в DevTools ширины: 360px, 430px, 768px, 1024px и 1440px. Проверить все страницы, отсутствие горизонтального скролла, изображения во вкладке Network и переход по Tab.

## Lighthouse
Нужно запустить Lighthouse в Chrome минимум для `index.html`, `catalog.html` и `order.html`, исправить оставшиеся предупреждения и сохранить реальный отчёт или скриншот в папку `lighthouse/`. Отчёт не подменён фиктивными результатами: после запуска сюда необходимо добавить `accessibility-report.html` или `accessibility-report.png`.
