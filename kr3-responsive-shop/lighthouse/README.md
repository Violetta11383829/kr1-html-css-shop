# Lighthouse Accessibility report

Сохраните сюда фактический отчёт Lighthouse или скриншот после запуска проверки в Chrome.

Минимум для проверки по методичке:
- главная страница;
- каталог;
- страница заявки.

Не добавляйте сюда выдуманные оценки. После проверки сохраните HTML-отчёт или скриншот с результатами.
